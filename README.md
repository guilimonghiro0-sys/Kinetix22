# KINETIX — L'Elite Digitale de Kinshasa

> "Nous architecturons le futur numérique de la RDC. Pas de templates. Pas de limites. Juste du code pur et de l'émotion."

Site vitrine officiel de **Kinetix Agency**, agence digitale d'élite basée à **Gombe, Kinshasa, République Démocratique du Congo**.

---

## À propos

Kinetix est née d'un constat : 90% des sites web en RDC étaient lents, non-sécurisés et basés sur des templates dépassés. Nous avons créé une **force spéciale du digital** pour changer ça.

Nous aidons les entreprises ambitieuses à dominer leur marché grâce à la technologie — sites immersifs, apps mobiles natives, architecture backend robuste et branding 3D.

## Stack technique

- **HTML5 / CSS3** — structure et styles de base
- **Tailwind CSS** — via CDN, utility-first
- **GSAP + ScrollTrigger** — animations cinématiques
- **Three.js** — particules WebGL en arrière-plan
- **Lucide** — icônes vectorielles
